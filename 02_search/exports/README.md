# Rohexporte aus Datenbanken

Hier lokal Exportdateien (RIS, CSV, BibTeX) der tatsächlich durchgeführten Suchläufe ablegen und den Pfad in `02_search/search_log.csv` (`export_path`) eintragen.

Exporte können lizenzierte Abstracts enthalten und sind deshalb per `.gitignore` von der Versionierung ausgeschlossen (öffentliches Repository). Nur diese README wird versioniert.
