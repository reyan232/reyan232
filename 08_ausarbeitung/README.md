# Ausarbeitungen von Claude

Hier legt Claude auf Wunsch des Studenten ausgearbeitete Texte ab: Folien, Thesenpapier, Studienarbeit und überarbeitete Fassungen (CLAUDE.md Regel 1, Entscheidung vom 2026-11-24). Inhalte sind per `.gitignore` von der Versionierung im öffentlichen Repository ausgeschlossen.

Pflichten bei jeder Ausarbeitung:
- KI-Anteil wahrheitsgemäß im KI-Protokoll (`00_admin/ki_nutzungsprotokoll.csv`) festhalten.
- Der Methodikteil der Arbeit beschreibt, wie KI eingesetzt wurde und wie Mensch und KI zusammengearbeitet haben; dazu die KI-Folie im Kolloquium (Folie 56).
- Jede Fachaussage mit geprüfter Originalquelle; nichts erfinden.
- Kernargumente und Quellenlage dem Studenten erklären, damit er sie verteidigen kann.

Eigene Fassungen des Studenten bleiben in `06_student_draft/`.
