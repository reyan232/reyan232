# Vorhandene wissenschaftliche Volltexte

Nur rechtmäßig zugängliche PDFs lokal ablegen (Hochschullizenz, Open Access, Fernleihe). Dateiname = `source_id` aus `literature.csv`, z. B. `Q001.pdf`. PDF-Dateien sind von Git ausgeschlossen (öffentliches Repository, Lizenzrecht). Kein Umgehen von Paywalls oder Lizenzregeln.

Ein Agent darf nicht behaupten, den Volltext gelesen zu haben, wenn er nicht wirklich zugänglich war. `access_level = VOLLTEXT_GELESEN` erst nach tatsächlicher Lektüre der relevanten Stellen.
