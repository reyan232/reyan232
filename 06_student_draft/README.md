# Ausschließlich studentischer Arbeitstext

Hier legt der Student seine eigene Seminararbeit ab. Agenten dürfen in diesem Ordner **keine Texte autonom erzeugen, editieren, löschen oder überschreiben**. Feedback in `07_feedback/` speichern. Auch bei ausdrücklichen Editierwünschen zuerst Hochschulregeln prüfen.
